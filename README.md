# Portofolio Finza Dwi Kirana

Website portofolio desain grafis (HTML + Tailwind CDN + JavaScript).

## Struktur
- `index.html` – halaman utama
- `css/style.css` – style tambahan
- `js/script.js` – interaksi (menu mobile, scroll spy, animasi)

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings → Pages → Branch `main` / root).
